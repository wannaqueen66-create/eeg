# Legacy Archive

This directory stores historical task-heavy analysis artifacts that are preserved for traceability but are **not part of the current `main` branch default surface**.

本目录用于保存历史性的 task-heavy 分析产物，保留以便追溯，但**不属于当前 `main` 分支默认对外展示的主结构**。

Currently archived here:
- ad-hoc / secondary helper scripts that are not part of the MATLAB/EEGLAB main pipeline
- historical QC analysis snapshots and task-oriented report bundles

Design intent:
- active `main` surface should prioritize the curated structure under `bandpower_outputs/runs/current/...`
- historical task-by-task exports remain available here for audit / reproducibility / retrospective reference

当前设计意图：
- `main` 的有效主界面应优先聚焦在 `bandpower_outputs/runs/current/...` 这套整理后的结构
- 历史的 task-by-task 输出保存在这里，供审计、复现和回溯参考
