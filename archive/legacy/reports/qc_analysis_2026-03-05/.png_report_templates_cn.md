# PNG 汇报模板（中文）

> 目标：让任何一个输出 PNG，都能用“**一句话结论 + 两句证据/解释**”讲清楚。

## 通用口播结构（推荐）
1. **这张图在回答什么问题**（自变量/分组、因变量/频段指标）。
2. **结论一句话**（是否有主效应/交互/趋势；方向：谁更高/更低）。
3. **证据一句话**（统计检验：F/df/p，或 t/p；必要时给 effect estimate/CI）。
4. **补一句解释**（它在行为/任务阶段上意味着什么；是否需要谨慎：可能受离群值影响等）。

## 图注模板（复制即可用）
- 图 X. <指标> 在 <分组方式> 下的 <效应类型>（QC 数据）。误差线为 <SEM/95%CI>（以图实际为准）。统计采用 <LMM/配对 t 检验>；显著性阈值 p<0.05。

## 你在 PPT 里放图的建议
- 每个 Task 最多放 1 张 overview 图 + 1–2 张关键效应图（其他放附录）。
- 同一 Task 内尽量保持同一配色/同一 y 轴含义，避免观众切换成本。
- 先放 **overview**（给全局），再放 **关键显著图**（给证据）。
